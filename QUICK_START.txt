## 🚀 Fastest Path to Launch (30 minutes)

### 1. PayPal Setup (5 min)
```
1. Go to developer.paypal.com
2. Sign up for Business account
3. Go to Apps & Credentials → Sandbox
4. Copy Client ID and Secret
5. Save them safely
```

### 2. GitHub Setup (5 min)
```
1. Create account on github.com
2. Create new repository
3. Clone locally
4. Add all files from this project
5. Commit and push
```

### 3. Netlify Deploy (5 min)
```
1. Go to netlify.com
2. Sign up with GitHub
3. New site from Git → Select your repo
4. Deploy!
```

### 4. Add Environment Variables (5 min)
```
In Netlify Dashboard:
Settings → Build & Deploy → Environment
Add:
- PAYPAL_CLIENT_ID = your_id
- PAYPAL_CLIENT_SECRET = your_secret
- DOWNLOAD_SECRET = any_random_text
```

### 5. Update Client ID (5 min)
```
In index.html, line 18:
<script src="https://www.paypal.com/sdk/js?client-id=YOUR_ID"></script>

Replace YOUR_ID with your actual Client ID
```

### 6. Test & Go Live!
```
Visit your Netlify URL
Click "Start Your 30-Day Transformation"
Test payment with PayPal sandbox
Should see success page
```

## 💰 How It Works

1. **User** clicks "Buy" button
2. **PayPal** checkout modal opens
3. **User** completes payment
4. **Backend** verifies with PayPal API
5. **User** redirected to success page
6. **Button** appears to download ebook
7. **File** delivered securely

No manual intervention needed!
